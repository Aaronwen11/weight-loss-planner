# 🍃 轻计划 · BMI 体重管理 / 减肥方案规划网页

一个纯静态、无需服务器、完全离线的多页面网页：
**填写问卷 → 生成个性化饮食 + 运动方案（含配图）→ 认可后创建每日打卡项目 → 打卡 + 体重记录 + 趋势图 + 每日提醒。**

## 使用方法

1. 用浏览器（推荐 Chrome / Edge / Safari）打开 `index.html`（双击即可，无需安装任何东西）。
2. 填写身高、体重、性别、年龄、职业、运动频率、目标、饮食习惯等问卷信息，点击「生成我的专属方案」。再次打开时会自动载入上次填写的数据，无需重新填写。
3. 在方案页查看身体数据解读、饮食方案（7 天轮换多样化食谱 + 每周放纵日 + 基础配图，全部含具体克数）、每周运动安排；减脂用户会看到专业饮食建议。
4. 认可方案后点击「认可方案，开始打卡」，设置**周期天数**与**每日提醒时间**，创建打卡项目。
5. 每天打开打卡页勾选任务、记录体重，查看体重趋势图与打卡日历。
6. 打卡页可设置**目标体重**查看达成进度条（接近目标时有火焰特效）；勾完当天全部任务会释放庆祝礼花；方案页提供**专业动作库**（划船、倒蹬、飞鸟、卧推等，附 B 站教学视频链接）。

## 算法说明

- **BMI** = 体重(kg) ÷ 身高(m)²；按中国标准分类：<18.5 偏瘦、18.5–23.9 正常、24–27.9 超重、≥28 肥胖。
- **BMR**：Mifflin-St Jeor 公式（男/女）。
- **TDEE** = BMR × 活动系数（由职业类型 × 每周运动频率得出，区间 1.2–2.0）。
- **热量目标**：减脂 = TDEE − 300~500 kcal（肥胖 −500），且不低于安全下限（男 ≥1500 / 女 ≥1200 kcal）；增肌 = TDEE + 300；塑形 = TDEE − 100；保持 = TDEE。
- **蛋白质**：减脂 1.4 g/kg、增肌 1.8 g/kg、塑形 1.5 g/kg、保持 1.2 g/kg。
- **饮水**：约 35 ml/kg，最低 1500 ml。

## 数据与隐私

- 所有数据仅保存在**当前浏览器**的 localStorage（键名 `zhi_wlp_*`），不上传任何服务器。
- 通过 `file://` 或隐私模式打开时，若浏览器禁用本地存储，页面会降级为内存模式（本次会话内有效）并在顶部提示。

## 提醒功能说明

- 每日提醒使用**浏览器 Notification API + 页面内提醒条**：到设定时间时，若网页处于打开状态（可切到后台标签页），会弹出系统通知并显示页面内提醒条与倒计时。
- ⚠️ **限制**：浏览器或页面完全关闭后无法推送通知（纯前端网页的固有限制）。建议把页面放在常开标签页，或每天主动打开打卡页。
- 提醒时间可在打卡页随时修改；可关闭/重新开启提醒；浏览器通知权限被拒绝时仍可使用页面内提醒。
